## 현재 상태 요약

| 항목 | 상태 |
|---|---|
| 환경 | Ubuntu 24.04, Isaac Sim 5.1, ROS 2 Jazzy (Isaac Sim 내장 브리지) |
| 최신본 | `tire_twin_all/tire_cell_v7_integrated` (v3 카메라·ROS 2·트랙 + v4~v6 너트 보관·재조립 + 비전 통합) |
| 시연 실행 | `bash run.sh` (ROS 토픽 포함) 전체 사이클 확인. `--no-ros` 측정값: 휠 탈거 76.5 mm → 재장착 오차 2.5 mm → 최종 0.6 mm / 0.01° → 트랙 이동 오차 0.17 mm, 322 s, 보호 정지 없음 |
| 비전 | 로봇 B D455 로 1회 촬영. 검출 결과 영상(`vision_debug.png`) 확인. 차 이동·휠 회전 조건에서 너트 오차 최대 0.29 mm |
| ROS 2 토픽 | 카메라 2대 컬러·깊이·camera_info·tf·clock. 토픽 켠 상태로 전체 사이클 실행 확인 |
| 차량 에셋 | 4종(CN7, K5, GN7, K9) 제작, 셀 시연은 아직 Prius 차체 사용 |

## 남은 작업

- 차량 4종, 트레이, 맵, `view.sh` Isaac Sim 실행 검증
- 뒷바퀴 탈거 (현재 트랙 이동만, 뒷바퀴는 분리되지 않는 단순 형상)
- 로봇 A 손목 카메라 활용 (너트 푼 뒤 휠 처짐 반영)
- 실기 대응: 핸드-아이 보정 행렬, 깊이 여러 장 평균, 너트러너 반력 바
- 가정값(`params.json` 의 `assumed`)을 실측·자료로 교체
- 차량 4종을 셀 시연에 연결
