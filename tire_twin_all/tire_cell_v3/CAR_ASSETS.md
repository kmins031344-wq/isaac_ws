# 차량 에셋 4종 (cars/)

`build_cars.py` 가 `car_specs.json` 의 제원으로 만든 에셋입니다. Isaac Sim 에서 실행 검증은 아직 하지 않았습니다.

```bash
~/isaacsim/isaac-sim.sh --open ~/cobot3_ws/isaac_assets/v3/cars/cars_ground.usda    # 4대 한꺼번에, 바닥 위 (받침대 위: cars_lineup.usda)
~/isaacsim/isaac-sim.sh --open ~/cobot3_ws/isaac_assets/v3/cars/k5_dl3_test.usda     # 1대씩 (avante_cn7 / k5_dl3 / grandeur_gn7 / k9_rj)
```

Play 를 누르면 받침대 4개 위에 차체가 얹히고 바퀴는 떠 있는 상태(리프트 상태)가 됩니다.

## 값의 출처

**현대 아반떼 CN7 (준중형) 가솔린 1.6, 17인치**

- 제조사 외 자료: 공차중량 1,270 kg (가솔린 1.6 17인치, 제원 정리 사이트가 옮긴 값. 현대 가격표로 재확인 필요), 디스크 지름 앞 280 / 뒤 262 mm (북미 제원 사이트 11.0 / 10.3 in)
- 가정: 앞뒤 무게 배분 61:39, 최저지상고 140 mm, 오버행 배분, 휠 오프셋 ET50, 디스크 두께, 휠+타이어 20 kg

**기아 K5 DL3 (중형) 2.0 가솔린, 18인치**

**현대 그랜저 GN7 (준대형) 가솔린 2.5, 18인치**

- 가정: 디스크 지름·두께(앞 325 / 뒤 300 mm, 공식 자료 미확인), 무게 배분 60:40, 최저지상고, 오버행 배분, 휠 오프셋 ET50, 휠+타이어 24.5 kg

**기아 K9 RJ (대형) 3.8 가솔린 2WD, 19인치**

- 공식: 전장/전폭/전고/축거/윤거(19인치)/공차중량 1,940 kg(3.8 2WD 19인치)/타이어 앞 245/45R19·뒤 275/40R19/앞뒤 벤틸레이티드 디스크 = 기아 K9 제원 (kia.com/kr/vehicles/k9/specification.html). 디스크 앞 14.2 in / 뒤 13.4 in = 기아 북미 공식 제원 (kiamedia.com, 2020 K900 = K9 RJ 수출명)

## 물리 구성 (차 1대 = 강체 13개, 관절 12개)

| 강체 | 내용 | 연결 |
|---|---|---|
| `Body` | 스프링 상 질량, 무게중심·관성 지정, 외판을 사각형 약 1,000개의 두께 6 mm 볼록판 충돌체로 | - |
| `Knuckle_*` | 너클, 캘리퍼, 스트럿 (회전 안 함) | `Joints/suspension_*` 직선 관절 + 스프링·댐퍼 |
| `Hub_*` | 허브, 디스크, 스터드 5개, 파일럿, 너트 5개(외형) | `Joints/axle_*` 회전 관절 (기본 브레이크 잠금) |
| `Wheel_*` | 휠 + 타이어 (타이어 링, 허브 보어, 스터드 구멍 충돌체) | `Joints/nut_clamp_*` 고정 관절 = 너트 체결 |

- 너트 체결 토크와 축력(F = T / (K·d), K 0.2 가정 → 너트 1개 약 45~53 kN)은 `nut_clamp_*` 관절과 각 너트 프림의 customData 에 기록만 되어 있습니다. 나사를 돌려 조이고 푸는 물리는 아직 없고, 고정 관절을 끄면 풀린 것으로 처리합니다.
- 브레이크를 풀려면 `axle_*` 의 `drive:angular:physics:stiffness` 를 0 으로 바꾸면 됩니다.
- 서스펜션 스프링 값은 공차 하중에서 계산한 값입니다(실차 스프링 제원 아님).
- 마찰계수는 `params.json` 의 값(타이어 고무 0.9/0.8, 강 0.5/0.4, 도장면 0.35/0.3)을 그대로 씁니다.

## 실제와 다른 점

- **차체 외형은 실차 CAD 가 아닙니다.** 로그인 없이 받을 수 있는 현대·기아 실차 CAD 는 찾지 못했습니다. 차체는 `car_body.py` 가 제원 치수(전장·전폭·전고·축거·윤거·타이어 지름)와 차종별 디자인 특징(지붕선, 보닛 높이, 그릴·램프 모양, 색, 휠 스포크)으로 만드는 절차적 모델입니다. 비례와 인상은 차마다 다르지만 실차의 곡면·캐릭터 라인은 재현하지 못합니다.
- 디자인 값은 `car_body.py` 의 `STYLES` 에 있고, 값을 바꾼 뒤 `python3 build_cars.py .` 로 다시 만들 수 있습니다. 실차 3D 모델(OBJ/FBX/GLB)을 구하면 차체만 교체할 수 있습니다.
- 허브·너클·캘리퍼·링크 모양은 치수 기반 단순 형상입니다. 액슬 너트 토크, 허브 베어링, 스프링 제원 같은 정비 지침서 값은 공개 자료가 아니라 넣지 못했습니다.
- 지금의 로봇 셀(`tire_cell_v3.usda`)에는 아직 연결하지 않았습니다. 차마다 휠 중심 높이와 타이어 지름이 달라서 그리퍼 벌림 폭과 로봇 경로를 차종별로 다시 잡아야 합니다.
